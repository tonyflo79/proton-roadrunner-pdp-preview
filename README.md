# Proton — Series Four · Project Roadrunner PDP (Preview)

High-fidelity dark-mode design preview for **Series Four — Project Roadrunner**, Proton's
flagship hybrid paddle. Built from the Flamingo/Peacock template (same design system) so the
lineup reads as one brand family.

This is a **staging preview only** — a single self-contained `index.html` (plain HTML/CSS + a
little vanilla JS) for stakeholder review of layout, typography, color, copy, and interactions.
The buy-box CTA is not wired to a real cart.

## Live preview
Served via GitHub Pages from `main` (root) once enabled:
`https://tonyflo79.github.io/proton-roadrunner-pdp-preview/`

## What's different about Roadrunner
- **Single configuration** — Elongated 16.5″ · 15mm · royal blue (no shape/thickness/color selector).
- **Bi-Directional Carbon-Kevlar Weave** face — carbon + Kevlar cross-woven; grit engineered into the weave; stays gritty across thousands of hits.
- **Touch-Power Hybrid Core** — Nomex + polypropylene; touch on the dink, power on the drive.
- **AeroGrade Construction™** (shared platform name, per canonical messaging).
- Dual-stamp **UPA-A + USA Pickleball**. Positioned on **speed + durability**. Warranty not showcased.
- Accent **royal blue** `#3E7BF0`.
